FindCrackedDevs

Describe the developer you need.

Plain-English search over a sample of public GitHub developers. Every result links to the real profile and comes with cited evidence.

~1,800developers in the index
1.03Mactive-account rows analysed
17developer domains sampled
384dimensions per embedding

Constraints

A demo built on free tiers and one laptop. These limits shape every result you see.

Small, biased corpus

~1,800 developers from accounts active in one 8-day window. The best match may not be indexed.

Keyword labels

Domains come from a hand-written dictionary with light auditing. About 46% of the sampled pool was unclassifiable.

Relevant, not best

Search measures similarity to your words. There is no quality or seniority ranking yet.

Dense retrieval only

No keyword hybrid search or reranker, so exact technologies can be blurred.

Thin profiles

Built from repo names, descriptions, topics and languages. READMEs and bios are not ingested yet.

Public data only

Private work and offline skills are invisible. Stars reflect visibility, not skill.

LLM can err

Summaries are told to cite repositories, but can still misread. Verify on the profile.

Free-tier limits

Rate limits, cold starts and model changes mean slow or unavailable moments.

Built on: Ubuntu Linux laptop, 7.6 GB RAM (often under 2 GB free), 4 GB swap, CPU only, Python 3.12. The bulk embedding job was killed twice by the out-of-memory killer, so it now runs in small batches. Data came from BigQuery’s free tier and the GitHub API (5,000 requests per hour).
